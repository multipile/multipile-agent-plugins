Publishes the multipile plugins to Claude Code and Codex as one marketplace, with each host's catalog generated from a single source so the two never drift.

The marketplace's identity and its list of plugins, the catalog each host reads, and the tooling that lints, builds and validates plugins belong here. So do the rules every plugin is held to, and how somebody contributes. A plugin itself does not, nor anything a plugin teaches.

Read this pile to find out how a plugin is added, checked and shipped to both hosts. Change it when a host changes what it reads from a marketplace, or the marketplace changes how it checks a plugin.
