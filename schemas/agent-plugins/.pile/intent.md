The Agent Plugins format as its published JSON Schemas, kept so a reader can check exactly what a plugin's manifest and its MCP configuration may say.

Copies of the published schemas, unchanged, belong here, each version of the format whole and beside the others, with a note of what each schema governs. Nothing in the build reads them: the build enforces the same rules by hand. Rules this marketplace adds of its own do not belong here.

Read this pile to find out what the Agent Plugins format allows. Change it when a new version of the format is published, or the marketplace moves to one.
