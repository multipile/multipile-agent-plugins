Packages the multipile skills as one installable, versioned plugin for Claude Code and Codex.

What both hosts show and install belongs here: the plugin's name, version, description and listing, and how a user installs and invokes it. A change to a skill reaches users only when the version here is bumped. What a skill says does not belong here.

Read this pile to find out what a user installs and which version they get. Change it when the skills are released, or the plugin is renamed, listed differently, or gains a component beside its skills.
